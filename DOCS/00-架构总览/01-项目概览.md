# 01 · 项目概览

## 1. 项目定位

**Missevan FM Recorder（猫耳 FM 主播直播流自动录制工具）** 是一款 Windows 优先（同时可编译 Linux）的 Tauri 2 桌面应用：

- 轮询「关注主播」的开播状态，检测到开播后自动拉起 FFmpeg 录制音频流（仅音频轨）；
- 提供一站式录制文件管理（搜索 / 日期分组 / 内置播放器 / 重命名 / 删除 / 自动清理）；
- 支持无人值守后台运行（系统托盘 + 开机自启 + 自动更新检查）。

> ⚠️ 免责声明（README 原文）：本软件仅供个人学习与研究使用；录制内容的版权归原权利人所有。

## 2. 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 桌面框架 | Tauri 2（`tauri = "2"`） | 双 Webview 窗口：`main`（主窗）+ `wizard`（设置向导） |
| 后端语言 | Rust 2021（MSRV 1.89.0） | 分层：`api` / `domain` / `infrastructure` |
| 后端异步 | tokio + tokio-util（CancellationToken / Notify / Semaphore） | 检测循环 / 录制任务均为异步任务 |
| 日志 | tracing + tracing-subscriber + tracing-appender | 文件滚动 + 内存环形缓冲 + 前端实时推送 |
| 前端框架 | Vue 3.5（`<script setup>`）+ TypeScript strict + Vite 8 | `vue-tsc` 类型检查 |
| 前端状态 | Pinia 4（setup 风格） | 10 个 store |
| 前端路由 | vue-router 4（hash 模式） | 双窗口共用同一路由表 |
| UI | reka-ui（Radix Vue 移植）+ shadcn-vue 风格组件 + Tailwind CSS 4 | `src/components/ui` 可复用组件集 |
| 国际化 | vue-i18n 10 | zh-CN / en 双语言，localStorage 持久化 |
| 图标 | @lucide/vue | — |
| 表格 | @tanstack/vue-table | 文件页表格视图 |
| FFmpeg 调用 | tokio::process 子进程 | 便携版优先（`{exe_dir}/ffmpeg/`），可配置路径，PATH 兜底 |
| 单实例 | fs2 文件锁 | 自实现（未用 tauri-plugin-single-instance） |
| 插件 | dialog / notification / opener / autostart | Tauri 官方插件 |

## 3. 功能矩阵（与 README 对齐）

| 功能 | 入口 | 核心代码 |
| --- | --- | --- |
| 直播监控（轮询 + 随机抖动 + 429 退避） | 后台 DetectionLoop | `domain/detector/loop.rs` |
| 双重验证开播判定（API ∥ 录制中） | 状态生产点 | `domain/detector/mod.rs::merge_live_state` |
| 自动录制（音频轨 / m4a/mp3 / 分段 / 码率） | DetectionLoop → engine | `domain/recorder/engine.rs`、`builder.rs` |
| 双录防御（进程表 / 并发上限 / 单实例） | engine + lib.rs setup | `engine.rs`、`infrastructure/single_instance.rs` |
| 崩溃熔断（CrashBackoff）与磁盘保护 | engine / monitor / loop | `domain/recorder/disk.rs` |
| 文件名模板渲染 | 录制启动前 | `domain/recorder/template.rs` |
| 文件缓存与页面 | 文件页 | `domain/services/file_cache.rs` + `views/files/*` |
| 自动清理（按天 / 按总量） | 手动 + 录制结束自动 | `domain/services/cleanup.rs` |
| 主播标签（固定 5 类） | 直播页 / 设置 | `src/lib/anchorTags.ts` + `domain/config/model.rs` |
| 系统通知（Windows 原生 toast） | NotificationDispatcher | `infrastructure/notification/*` |
| 系统托盘（动态菜单） | TrayManager | `infrastructure/tray/mod.rs` |
| 首启设置向导（4 步 + FFmpeg 下载） | wizard 窗口 | `views/wizard/*` + `api/wizard_cmds.rs` |
| 调试面板（日志 / 网络 / 引擎状态 / Mock） | debug 路由（默认关闭） | `views/debug/*` + `api/debug_cmds.rs` |
| 自动更新检查 | 关于窗口 | `api/update_cmds.rs` |
| 健康检查（FFmpeg / 磁盘 / 权限） | 向导 + 设置页 | `infrastructure/checker/*` |
| 单实例运行 | 进程锁 | `infrastructure/single_instance.rs` |
| 中英双语 / 主题 / 强调色 / 密度 / 字号 | 外观设置 | `locales/*` + `stores/appearanceStore.ts` |

## 4. 版本与许可

- 版本：`0.1.0`（Cargo.toml / package.json / tauri.conf.json 三处一致）
- 许可证：MIT（`LICENSE`）
- 发布标识：`com.missevan-recorder.app`；产品名 `missevan-recorder`
- 目标平台：Windows 10/11（NSIS 安装包，release workflow）；Linux 可编译（deb/appimage 目标存在，托盘未集成，见后端决策）
- 内置 FFmpeg 二进制遵循其自身 LGPL/GPL 许可
