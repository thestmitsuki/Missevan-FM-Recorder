## 代码行规模（近似）

| 侧 | 规模 |
| --- | --- |
| 后端 Rust（`src-tauri/src`） | ~20 个模块文件，含大量 `#[cfg(test)]` 单测 |

| 工程配置 | tauri.conf.json / 2 个 capability / 8 个 permission 文件 / 2 个 CI 工作流 |

## 文档约定

- 所有文档以**中文**撰写（与仓库代码注释语言一致）。
- 引用代码路径均相对仓库根目录（如 `src-tauri/src/domain/recorder/engine.rs`）。
- 「审查发现」小节标注的是架构观察，不一定是缺陷；「已知陷阱」小节用于防止后续开发踩坑。
- 命令/事件/字段名与代码逐字对齐（snake_case / 小写事件名）。
