## 2. 关键架构决策

1. **双窗口同一前端**：`App.vue` 按 `isWizardWindow()` 分流；wizard 窗只渲染 `WizardView`（无 AppLayout）。
2. **通信收敛**：页面/组件**不直接 invoke/listen**——`services/api.ts` 与 `services/events.ts` 是唯一桥接点；事件经 store 订阅后页面消费（如 `anchorStore.startListening`）。
3. **UI 偏好前端化**（D5）：语言/主题/外观/调试开关存 localStorage，不进 GlobalConfig；业务数据（配置/主播/文件）走后端。
4. **类型契约逐字对齐后端**：`types/*` 注释标明后端来源文件；`configStore.DEFAULT_CONFIG` 与后端 `GlobalConfig::default()` 核对过（Task 3）。
5. **i18n 全覆盖**：所有用户可见文案走 `t()`，zh-CN/en 同步维护；标签落盘用中文规范值（与 UI 语言解耦）。

| 路径 | name | 组件 | 守卫 |
| --- | --- | --- | --- |
| `/` | live | `views/live/LiveView.vue` | — |

hash 模式（`createWebHashHistory`）——Tauri asset 协议下无需服务端路由。
