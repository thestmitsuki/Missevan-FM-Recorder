# 后端概览（src-tauri/src）

## 1. 分层与模块地图

```
src-tauri/src/
├── main.rs                # 入口（Windows release 无控制台窗口）
├── lib.rs                 # 应用装配：panichook/日志/单实例/共享状态/Tauri Builder/命令注册/setup/关闭流程
├── api/                   # ── 命令层（薄壳，54 个 Tauri 命令）──
│   ├── anchor_cmds.rs     # 主播：get_anchors / add / remove / refresh / update / profile / recording_status / stop_anchors_recording
│   ├── config_cmds.rs     # 配置：get/save/export/import/reset_config、set_autostart、set_shortcut、run_cleanup_now
│   ├── debug_cmds.rs      # 调试：health_check、debug_info、logs、network_logs、detector_stats、recorder_state、file_cache_state、mock_state、diagnostic_report 等 14 个
│   ├── file_cmds.rs       # 文件：get/refresh_recording_files、rename/delete/play_recording_file
│   ├── recording_cmds.rs  # 录制：start_recording（占位禁用）、stop_recording
│   ├── mock_cmds.rs       # Mock：set_mock_live_data/set_mock_mode/list/add/update/remove_mock_anchor、set_all_mock_live、reset_mock（8 个）
│   ├── update_cmds.rs     # 更新：check_update、get_app_info、open_browser
│   ├── wizard_cmds.rs     # 向导：download_ffmpeg、run_wizard_health_check、exit_app、finish_wizard（4 个）
│   └── fs_utils.rs        # open_output_dir
├── domain/                # ── 领域层（业务规则，纯 Rust，高单测覆盖）──
│   ├── config/{model,manager}.rs   # 配置模型 + 原子读写/备份/导入导出/混淆落盘
│   ├── detector/{loop,stats,mod}.rs # 检测循环/统计/直播状态归并
│   ├── recorder/{builder,disk,engine,monitor,template}.rs # FFmpeg 录制全链路
│   ├── services/{cleanup,file_cache,fs_walk}.rs            # 清理/文件缓存/安全遍历
│   ├── spider.rs          # 猫耳 API 客户端（check_live/profile/错误分类/网络插桩）
│   └── tools.rs           # ffmpeg/ffprobe 路径解析 + CREATE_NO_WINDOW + 子进程回收

    ├── state/{app_state,mock_store}.rs

    ├── notification/{dispatcher,types,buffer,windows_toast}.rs

    ├── checker/{checks,runner,report}.rs
    ├── crypto/mod.rs
    ├── error/types.rs
    └── single_instance.rs
```

## 2. 依赖方向

- `api → domain + infrastructure`（命令壳依赖一切）。
- `domain` 内部：`recorder → services/file_cache`、`recorder/spider → infrastructure/{notification,logging,state,error}`（**横切面例外**，设计取舍见架构总览 §6.1）。
- `infrastructure` 内部：`state/app_state → domain/recorder/disk`（复用 CrashBackoff / DiskNotifyThrottle / now_ms）；`checker/checks → domain/tools`。
- `lib.rs` 负责把所有 Arc 共享状态注入 Tauri 托管（`.manage()`）并注册命令。

## 3. 共享状态（Tauri Managed）

| 状态 | 类型 | 注册点（lib.rs） | 主要消费方 |
| --- | --- | --- | --- |
| `RecorderState` | `Arc<AppState>` | `.manage(recorder_state)` | 全部 api 命令 |
| `FfmpegRecorder` | `Arc<FfmpegRecorder>` | `.manage(recorder_shared)` | loop/monitor/shutdown |
| `ConfigManager` | `Arc<ConfigManager>` | `.manage(config_manager)` | 全部 api 命令 |
| `NotificationDispatcher` | `Arc<NotificationDispatcher>` | `.manage(notifier)` | engine/monitor/loop/cmds |
| `FileCacheHandle` | `Arc<Mutex<FileCacheManager>>` | `.manage(file_cache)` | file_cmds/cleanup/engine |
| `live_cache` | `Arc<Mutex<HashMap<String,bool>>>` | `.manage(live_cache)` | loop/anchor_cmds |
| `avatar_cache / avatar_negative_cache` | AvatarCache 类型 | `.manage` | anchor_cmds（头像 O2 负缓存） |
| `detection_wake` | `Arc<Notify>` | `.manage` | finish_wizard |
| `log_buffer / network_store` | `Arc<LogBuffer>` / `Arc<NetworkStore>` | `.manage` | debug_cmds |
| `mock_store` | 内嵌于 RecorderState | — | loop/mock_cmds |

## 4. 错误模型（infrastructure/error/types.rs）

- 单一错误类型 `AppError`，携带：`code`（常量错误码）、`category`（Config/System/Network/Recording/Internal...）、`severity`（Error/Warning/Info）、`message`（用户可读）、`suggestion`（可选）、`technical`（可选，脱敏后进日志）。
- 错误码分组：`CF_*`（配置）、`NF_*`（系统/FFmpeg）、`NW_*`（网络）、`RC_*`（录制）、`INT_*`（内部）、`IO_*`（IO）等。
- 命令层 `Result<T, AppError>` 序列化给前端；前端 `services/api.ts` 捕获后按 `code` 展示。

## 5. 测试概况

- 所有模块内置 `#[cfg(test)]` 单测；`cargo test` 全绿是 CI 门槛。
- 测试覆盖重点：配置解析/字段校验/备份轮转、模板渲染边界、路径清理/防逃逸、退避与熔断、429 冷却、通知过滤矩阵、错误码、MockStore、环形缓冲、日志脱敏、单实例锁、ffmpeg 命令参数、URL 校验等。
- 托盘/通知/Tauri 命令本身不可单测（依赖平台 API），可测部分（菜单数据构建、关闭决策、URL 放行）已抽出纯函数并单测。
