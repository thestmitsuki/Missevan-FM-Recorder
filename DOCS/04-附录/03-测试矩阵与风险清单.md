## 3. 风险清单（架构审查产出）

### 高风险（改动需格外谨慎）

| # | 风险 | 位置 | 缓解 |
| --- | --- | --- | --- |
| R1 | 双录回归：新路径绕过进程表/并发防线 | engine / loop / monitor | 启动录制只能走 `start_ffmpeg_recording`；单测覆盖防线 |

## 4. 升级/重构注意

- **Tauri 2.x 升级**：Cargo.toml 语义版本宽松（`tauri = "2"`），升级依赖后必跑 `cargo test`（通知/权限/ACL 行为可能变化）并回归 capabilities 权限。
- **reka-ui 升级**：ui 组件原语 API 可能破坏（弹层/焦点/键盘），需全量回归。
- **Tailwind 4**：已用 `@tailwindcss/vite`（非 postcss 方案），升级注意构建链。
- **Rust edition/MSRV**：MSRV 1.89.0（依赖树最高）；升级 Rust 工具链无碍，但依赖解析（Cargo.lock）变更需审查。
