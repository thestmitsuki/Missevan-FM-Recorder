## 2. 事件（7 个）

| 事件 | 载荷 | 生产者 → 消费者 |
| --- | --- | --- |
| `recording_status_changed` | `AnchorStatusUpdate{anchor_id,is_live,is_recording}` | engine/monitor/detector → anchorStore |
| `recording_files_changed` | `RecordingFilesPayload{files,folders}` | file_cache → fileStore |
| `app:notification` | `Notification` | dispatcher → notificationStore |
| `debug:log` | `LogEntry`（节流 100/s） | LogLayer → 调试页日志 |
| `mock:status_changed` | `MockStatusChanged{enabled,count}` | mock_cmds → mockStore/调试页 |
| `tray:open_live_page` | 无 | TrayManager → App.vue（跳直播页） |
| `download:progress` | `DownloadProgress{percent,stage}` | wizard_cmds（Windows）→ 向导进度条 |
