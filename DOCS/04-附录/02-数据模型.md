# 02 · 数据模型（配置与持久化格式）

## 1. 配置文件布局

```
数据目录（dirs::data_dir()/missevan-recorder，平台相关）
├── config.toml              # 全局配置（TOML，敏感字段 enc:v1: 混淆）
├── config.toml.bak.<YYYYMMDDHHMMSSmmm>  # 备份（保留最近 5 份）
└── anchors/
    └── <anchor_id>.toml     # 每主播独立文件（AnchorConfig）
```

## 2. GlobalConfig（config.toml）

```toml
output_dir = "./recordings"        # String
record_format = "m4a"              # "m4a" | "mp3"
segment_seconds = 0                # u64，0=不分割
disk_space_limit_gb = 10           # u64，0=不限制
ffmpeg_path = null                 # Option<String>
anchor_ids = []                    # 遗留字段（不使用，兼容旧配置）
check_interval_secs = 120          # u64
max_retries = 3                    # u32
retry_delay_secs = 5               # u64
autostart = false                  # bool
close_behavior = "tray"            # "tray" | "exit"
show_tray = true                   # bool
check_updates = true               # bool
bitrate_kbps = 128                 # u32
audio_only = true                  # bool
filename_template = "{anchor_name}/{date}_{time}_{anchor_name}.{ext}"  # 默认模板
pre_record_delay_secs = 0          # u64 开播→录制延迟（可取消）
max_concurrent_recordings = 0      # u64，0=不限
# 通知
notifications_enabled = true
notify_system = true
notify_sound = false
notify_recording_start = true
notify_recording_end = true
notify_recording_error = true
notify_live_start = true
notify_live_end = true
notify_disk_warning = true
notify_update = true
# 代理
proxy_type = "none"                # "none" | "http" | "socks5"
proxy_url = ""
proxy_port = 0
proxy_username = ""
proxy_password = ""                # 落盘混淆 enc:v1:...
# 录制后行为
post_record_action = "none"        # "none" | "open_folder" | "command"
post_record_command = ""           # 支持 ${output} 占位
# 日志
log_level = "info"                 # error|warn|info|debug|trace（运行时热更新）
# 遗留（兼容，不使用）
cleanup_time = null
```

## 3. AnchorConfig（anchors/<id>.toml）

```toml
id = "uuid"                        # String
name = "主播名"
url = "https://fm.missevan.com/live/123456"
room_id = "123456"
proxy = null                       # Option<String>
cookie = null                      # Option<String>（混淆落盘）
enable_check = true                # bool
tags = ["音乐", "杂谈"]            # Vec<String>，固定 5 标签（中文规范值）
# avatar_url 动态获取，不落盘
```

## 4. 前端持久化（localStorage）

| 键 | 内容 | 归属 |
| --- | --- | --- |
| `locale` | `"zh-CN"` / `"en"` | i18n |
| `theme_mode` | `"light"` / `"dark"` / `"system"` | themeStore |
| `appearance` | JSON：accent / fontSize / density / cardShow* | appearanceStore |
| `debug_enabled` | `"1"` / 无 | debugStore |
| `live_view_mode` | `"card"` / `"list"` | anchorStore |
| `live_filters` | JSON：searchQuery / tagFilter / recordFilter / liveFilter | anchorStore |

**注意**：无 `wizard_done` 类完成标记（已移除，M7）；首启判定 = 配置文件是否存在。

## 5. 序列化细节（前后端契约）

| 类型 | 序列化形态 | 前端处理 |
| --- | --- | --- |
| `std::time::SystemTime` | `{secs_since_epoch, nanos_since_epoch}` | `systemTimeToDate()`（types/file.ts） |
| `Option<String>` | `null` / 字符串 | `string \| null` |
| 通知时间戳 | RFC3339（chrono Local） | 直接 new Date() |
| 日志时间戳 | RFC3339 | 直接展示 |
| 枚举（close_behavior 等） | 字符串 | 联合类型（与后端逐字一致） |

## 6. FFmpeg 便携版布局

```
{exe_dir}/ffmpeg/ffmpeg.exe    # Windows 向导下载解压产物（候选顺序第 2 位）
{exe_dir}/ffmpeg/ffprobe.exe
```

候选顺序：配置 `ffmpeg_path` → `{exe_dir}/ffmpeg/<tool>.exe` → PATH 裸名（tools.rs 统一）。
